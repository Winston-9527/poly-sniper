# telegram-alerts Spec Delta

## 新增需求

### 需求：手动分析指令
系统**必须**支持通过 Telegram 指令触发对特定市场的手动分析。

#### 场景：请求分析
- **给定**：用户向机器人发送 `/suspicious` 指令。
- **并且**：用户的 Chat ID 在授权列表中。
- **那么**：机器人应回复提示信息，要求用户输入 Polymarket 市场链接。

#### 场景：执行分析
- **给定**：机器人处于"等待链接"状态。
- **当**：用户发送有效的 Polymarket 链接（如 `https://polymarket.com/event/...`）。
- **那么**：机器人应：
    1. 解析链接获取市场标识（Slug）。
    2. 调用 Profiler 对该市场进行画像分析。
    3. 返回分析结果（高疑钱包列表或"未发现异常"）。

### 需求：交互状态管理
系统**必须**能够维护简单的会话状态，以区分普通消息和对指令的回复。

#### 场景：非指令消息
- **给定**：机器人未处于任何指令等待状态。
- **当**：收到普通文本消息。
- **那么**：机器人应忽略该消息。

### 需求：权限控制
系统**必须**限制交互功能仅对配置的 `TELEGRAM_CHAT_ID` 生效。

#### 场景：未授权访问
- **给定**：未授权的用户发送指令。
- **那么**：机器人应忽略该指令，不产生任何回复。
