# 提案：实现 Telegram 异动警报推送

## 为什么
目前系统的异动警报仅在控制台输出，用户无法实时接收通知。为了实现“实时预警”的目标，需要集成 Telegram 机器人，将异动信息推送到用户的移动端或桌面端。

## 变更内容
1.  **集成 Telegram Bot SDK**：引入 `node-telegram-bot-api` 或类似的轻量级库。
2.  **实现 Messenger 模块**：创建一个专门负责消息推送的模块，解耦监控逻辑与推送逻辑。
3.  **增强警报信息**：在原有的异动信息基础上，增加 Polymarket 市场的直接链接，方便用户快速跳转下单。
4.  **配置管理**：支持通过环境变量配置 Telegram Bot Token 和 Chat ID。

## 风险与考虑
- **网络连通性**：Telegram API 在某些环境下可能需要代理，需确保推送模块支持代理配置。
- **推送频率**：如果异动频繁，可能会触发 Telegram 的频率限制，需考虑简单的消息队列或合并推送。
- **隐私安全**：Bot Token 必须通过环境变量管理，严禁硬编码。
