# 规范：REST 轮询监控

## 新增需求

### 需求：移除 WebSocket 实时订阅
系统**必须**停止使用 WebSocket 协议监听价格变动，以规避连接不稳定和订阅数量限制。

#### 场景：系统启动
- **给定**：系统配置为监控 1000 个市场。
- **当**：系统启动时。
- **那么**：系统不应尝试连接 `wss://ws-subscriptions-clob.polymarket.com`。

### 需求：基于 REST API 的定时轮询
系统**必须**通过定时调用 REST 接口获取全量市场价格。

#### 场景：周期性采样
- **给定**：轮询间隔设置为 10,000 毫秒。
- **当**：计时器触发时。
- **那么**：系统应请求 `https://clob.polymarket.com/sampling-simplified-markets`。
- **并且**：将返回的所有 Token 价格更新发送至 `AnomalyDetector`。

### 需求：代理环境兼容性
系统**必须**在配置了 `HTTPS_PROXY` 的环境下正常发起 REST 请求。

#### 场景：代理请求
- **给定**：环境变量 `https_proxy` 已设置。
- **当**：发起轮询请求时。
- **那么**：请求应通过指定的代理服务器转发。
