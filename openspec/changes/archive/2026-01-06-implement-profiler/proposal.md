# 提案：实现钱包画像与内幕打分模块 (The Profiler)

## 为什么
单纯的价格异动监控只能告诉我们“发生了什么”，但无法告诉我们“是谁在买”以及“这是否是内幕交易”。通过对异动市场的持仓者进行画像分析，我们可以识别出具有内幕特征的钱包（如新号重仓、资金来源可疑等），从而大幅提高预警的准确性和参考价值。

## 变更内容
1.  **新增 Profiler 模块**：
    *   实现 `GammaClient`：用于从 Polymarket Gamma API 获取市场的 Top 持仓者列表。
    *   实现 `ChainAnalyzer`：利用 `ethers.js` 连接 Polygon RPC，查询钱包的初始交易时间、余额等链上数据。
    *   实现 `Scorer`：根据预设维度（账号新鲜度、资金实力、专注度等）对钱包进行打分。
2.  **集成至 Sentinel 流程**：
    *   在 `Sentinel` 检测到价格异动后，自动触发 `Profiler` 对该市场进行扫描。
    *   将扫描结果（高分可疑钱包）传递给推送模块。
3.  **增强 Telegram 警报**：
    *   在推送信息中增加“内幕分析”板块，列出高分钱包及其打分详情。
4.  **配置扩展**：
    *   支持配置 Polygon RPC 节点地址。
    *   支持配置打分权重的阈值。

## 风险与考虑
- **API 频率限制**：Gamma API 和 RPC 节点都有频率限制。需要实现并发控制和缓存机制，避免在异动频繁时被封禁。
- **分析耗时**：链上分析（尤其是查询首笔交易）可能较慢。需要采用异步处理，确保不阻塞主监控循环。
- **误报风险**：大户的正常调仓可能被误判。需要通过多维度打分（而非单一维度）来降低误报率。
