# Sentinel Monitoring Specification

## 新增需求
### 需求：高阶市场过滤
系统必须在监控源头过滤掉低价值或高噪音的市场。

#### 场景：过滤低流动性市场
- **给定** 一个市场发生价格异动。
- **当** 该市场的流动性 (Liquidity) 小于 $10,000 时。
- **那么** 系统应忽略该异动，不进行打分或推送。

#### 场景：过滤短时 Crypto 期权
- **给定** 一个 Crypto 类别市场。
- **当** 其标题或描述包含 "15m", "1h", "4h", "Daily Up/Down" 等短期/二元期权关键词时。
- **那么** 系统应将其排除。

#### 场景：排除体育博彩
- **给定** 一个市场。
- **当** 其类别为 "Sports" 时。
- **那么** 系统应将其排除。

#### 场景：保留 Pre-market
- **给定** 一个名为 "Bitcoin September Pre-market" 的市场。
- **当** 系统进行过滤检查时。
- **那么** 即使它包含 "Bitcoin"，也应因包含 "Pre-market" 关键词而被**保留**。
