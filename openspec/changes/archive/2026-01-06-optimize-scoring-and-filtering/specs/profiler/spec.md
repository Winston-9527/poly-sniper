# Profiler Specification

## 修改需求
### 需求：多维度打分体系
系统必须更新内幕钱包画像的打分权重配置，强调“精准狙击”特征（新鲜度、专注度）并引入多钱包关联性分析，以提高内幕识别的准确率。

#### 打分算法规则
更新打分权重配置，强调“精准狙击”特征并引入关联性分析。

**新的权重分布 (总分 100)**：

1. **账号新鲜度 (Freshness)** - 权重 30% (Max 30分)
   - 交易次数 < 5: 30分
   - 交易次数 < 20: 20分
   - 交易次数 < 50: 10分

2. **专注度 (Focus)** - 权重 30% (Max 30分)
   - 参与市场数 = 1: 30分
   - 参与市场数 <= 3: 15分

3. **本市场持仓 (Position)** - 权重 20% (Max 20分)
   - 持仓价值 > $50,000: 20分
   - 持仓价值 > $10,000: 15分
   - 持仓价值 > $1,000: 5分

4. **关联性 (Correlation)** - 权重 10% (Max 10分)
   - 检测到同源资金 (Funded by same source): 10分
   - 否则: 0分

5. **资金储备 (Capital)** - 权重 10% (Max 10分)
   - USDC 总余额 > $50,000: 10分
   - USDC 总余额 > $10,000: 5分

**警报阈值**：
- 当总分 **≥ 60** 分时，视为高疑内幕，触发推送。

#### 场景：计算包含关联性的得分
- **给定** 两个钱包 A 和 B。
- **当** 它们均由同一地址 C 注资（且 C 不是交易所），且 A 为新号（+30）、单一市场（+30）、持仓 $2000（+5）。
- **那么** 钱包 A 获得关联分（+10），总分为 30+30+5+10 = 75分 > 60分，触发警报。
