# 规范：实时异动监控 (Sentinel)

## 概述
定义 Sentinel 模块如何监控 Polymarket 市场并识别价格异动。

## 新增需求

### 需求：市场订阅与过滤
系统必须订阅 Polymarket 的实时价格流，并仅处理特定类别的市场。

#### 场景：排除特定类别的市场
- **给定** 系统已启动并连接到 Polymarket WebSocket。
- **当** 收到一个属于 "Crypto" 或 "Sports" 类别的市场更新时。
- **那么** 系统应忽略该更新，不进行异动分析。

#### 场景：处理目标类别的市场
- **给定** 系统已启动。
- **当** 收到一个非 "Crypto" 且非 "Sports" 类别的市场更新时。
- **那么** 系统应将其传递给异动检测逻辑。

### 需求：价格异动检测
系统必须能够识别并报告价格的显著波动。

#### 场景：检测到价格波动超过 5%
- **给定** 市场 A 的上一个记录价格为 0.50。
- **当** 收到市场 A 的新价格为 0.53（波动 6%）或 0.47（波动 6%）时。
- **那么** 系统应输出异动警报，包含市场 ID、当前价格和波动幅度。

#### 场景：价格波动低于 5%
- **给定** 市场 A 的上一个记录价格为 0.50。
- **当** 收到市场 A 的新价格为 0.51（波动 2%）时。
- **那么** 系统应更新内存中的最新价格，但不触发警报。

## 输出格式
异动警报应包含以下字段：
- `market_id`: 市场的唯一标识符。
- `current_price`: 当前成交价格。
- `change_percentage`: 波动百分比（如 "+6.00%" 或 "-5.50%"）。
