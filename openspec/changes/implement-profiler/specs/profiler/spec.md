# Profiler Specification

## 新增需求
### 需求：持仓者画像分析
系统必须能够对异动市场的持仓者进行自动化画像分析，以识别潜在的内幕交易行为。

#### 场景：识别新鲜重仓钱包
- **给定** 市场 A 发生价格异动。
- **当** 系统扫描市场 A 的持仓者时。
- **那么** 系统应识别出创建时间少于 48 小时且持仓量排名前 20 的钱包。
- **并且** 将其标记为“高疑内幕钱包”。

### 需求：多维度打分体系
系统必须根据多个行为维度对钱包进行量化打分。

#### 打分算法规则
钱包的总分由以下四个维度的权重分累加而成：

1. **账号新鲜度 (Account Freshness)** - 权重 Max 40
   *用于识别专门为此次操作创建的小号。*
   - 交易次数 < 5: **40分** (极新账号)
   - 交易次数 < 20: **30分** (次新账号)
   - 交易次数 < 50: **15分** (近期活跃)

2. **持仓规模 (Position Size)** - 权重 Max 40
   *用于衡量 Skin in the game 的程度，投入越大越可疑。*
   - 持仓价值 > $50,000: **40分** (重仓出击)
   - 持仓价值 > $10,000: **30分** (大额投注)
   - 持仓价值 > $1,000: **15分** (中额投注)
   - 持仓价值 > $100: **5分**

3. **资金储备 (Capital)** - 权重 Max 10
   *用于辅助判断资金实力。*
   - USDC 余额 > $10,000: **10分** (弹药充足)
   - USDC 余额 > $1,000: **5分**

4. **专注度 (Focus)** - 权重 Max 10
   *用于识别单一目的的狙击行为。*
   - 参与市场数量 = 1: **10分** (单一市场)

#### 场景：计算内幕得分
- **给定** 一个钱包地址。
- **当** 其满足“交易次数为 1（+40分）”、“持仓价值 $12,000（+30分）”、“余额 $500（+0分）”且“仅参与单一市场（+10分）”时。
- **那么** 该钱包的内幕得分应为 80 分。

### 需求：分析结果推送
系统必须在警报中包含画像分析的关键结论。

#### 场景：推送包含内幕分析的警报
- **给定** 市场 A 检测到异动，且 Profiler 识别出 2 个得分超过 60 的钱包。
- **当** 发送 Telegram 警报时。
- **那么** 警报信息中必须包含“内幕分析”板块，列出这两个钱包的地址、得分及主要可疑特征。
